# Xtube

Xtube is a backend service for a **video streaming and social media platform**, inspired by features commonly found in platforms like YouTube and X (Twitter). It provides scalable APIs for user management, video content handling, and social interactions.

The backend is built using **Node.js and Express**, with **MongoDB** as the primary database and **MongoDB Atlas** for cloud-based data storage. Media assets such as videos and thumbnails are managed using **Cloudinary**, enabling efficient upload, storage, and delivery.

This project focuses on backend architecture, RESTful API design, authentication, and database modeling for a modern, video-centric social media application.

### Tech Stack

* **Node.js**
* **Express.js**
* **MongoDB**
* **MongoDB Atlas**
* **Cloudinary**
* **JWT-based Authentication**

### Core Features

* User authentication and authorization
* Video upload and management
* Likes, comments, and subscriptions
* Channel and user profiles
* Scalable REST APIs for social interactions

This project is intended for learning, experimentation, and portfolio demonstration of backend development concepts for large-scale media platforms.
